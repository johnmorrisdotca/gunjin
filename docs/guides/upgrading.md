## This documentation rollout

The 0.2.0 engines, ten entry paths, rosters and native player keep their behavior. The API index keeps export anchors; reference pages add checked examples and precise parameters/returns. Existing detailed Rules/API documents and README examples remain preserved.

## Update a host deliberately

Retain mode, size, setup and turn counters, original protocol version and stored trust boundary. Review a setup/handoff, legal move, stale rejection, redacted view, public replay and trusted decoder on the chosen version. Public decoding validates structure rather than authenticating a match. Read [the changelog](../../CHANGELOG.md) before updating saved games; the package remains in 0.x.
