## 隠した情報と受け付けない操作

- 駒の `pieces` が null なら、配置や受け渡しで盤を隠しています。
- 相手の `kind` が null なら階級を隠し、ID もありません。
- `ownSetup` が null なら、配置中ではありません。
- winner が null なら合意の引き分けで、結果そのものがなければ未終了です。
- 読み取りが null なら、その形式や構造を受け付けません。
- 駒一覧、配置、配置の段階、手番、操作する側が不正なら、標準の RangeError です。

## ゲームと保存形式を分ける

そのゲームの駒と地形の制限を使います。完全な保存のプロパティ名を変えても公開にはなりません。公開の再生から秘密の配置は戻せません。表示のハンドルも、公開してよい表示と再生だけです。表示先を取り除くときは破棄し、[完全な規則](../../RULES.md)と[API の概要](../../API.md)を保って導入します。
